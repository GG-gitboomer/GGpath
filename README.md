# GGpath

A web-based 3D model visualizer for CSI SAP2000 $2k / .s2k text export files (supporting versions v22 to v26).

## Live Demo

Access the live viewer via GitHub Pages:
https://gg-gitboomer.github.io/GGpath/

## Features

- Parses and visualizes SAP2000 $2k / .s2k text files (v22 to v26).
- Interactive 3D model viewing directly in the browser.
- No external dependencies required to run the web interface.

## Usage Instructions

1. Open the GitHub Pages live viewer or open `index.html` locally in a web browser.
2. Export your SAP2000 structural model as a $2k or .s2k text file.
3. Import or drag-and-drop the file into the web visualizer interface to view the 3D model.
